Question:
Determine the pH of an HF solution of each of the following concentrations. In which cases can you not make the simplifying assumption that x is small?
(Ka for HF = 6.8 × 10⁻⁴).
Express each answer to two decimal places.

1. 0.220 M


2. 0.0530 M


3. 0.0240 M




---

Concept Refresher (Clarity & Voice)

Hydrofluoric acid (HF) is a weak acid, which means it doesn’t completely dissociate in water. The dissociation looks like this:

HF ⇌ H⁺ + F⁻

To find the pH, we need the concentration of H⁺ ions in solution. We’ll do this using the ICE table method, and check whether we can make the “x is small” assumption (which simplifies the math).


---

Step-by-step plan (Structure)

General setup:

Let’s assume:

Initial [HF] = C

[H⁺] formed = x

Ka = 6.8 × 10⁻⁴


So the expression becomes:
Ka = x² / (C - x)


---

Case 1: [HF] = 0.220 M

Step 1: Try “x is small” approximation

Assume C - x ≈ C, so:
Ka = x² / C →
x² = Ka × C = (6.8×10⁻⁴)(0.220) = 1.496×10⁻⁴
→ x = √(1.496×10⁻⁴) = 0.01223 M

Now, check if “x is small”:
Is x / C < 5%?
→ 0.01223 / 0.220 = 0.0556 or 5.56%

Conclusion:
This is more than 5%, so we CANNOT use the approximation. We need to solve the full quadratic.

Step 2: Use full equation

x² / (0.220 - x) = 6.8×10⁻⁴
→ Multiply both sides:
x² = 6.8×10⁻⁴(0.220 - x)
x² = 1.496×10⁻⁴ - 6.8×10⁻⁴x
→ Rearranged:
x² + 6.8×10⁻⁴x - 1.496×10⁻⁴ = 0

Use quadratic formula:
x = [-b ± √(b² - 4ac)] / 2a
Here: a = 1, b = 6.8×10⁻⁴, c = -1.496×10⁻⁴

→ x = [ -6.8×10⁻⁴ ± √( (6.8×10⁻⁴)² + 4×1×1.496×10⁻⁴ ) ] / 2

→ x = 0.01201 M (only positive root makes sense)

Step 3: Find pH

pH = -log[H⁺] = -log(0.01201) = 1.92


---

Case 2: [HF] = 0.0530 M

Step 1: Try x is small

x² = Ka × C = (6.8×10⁻⁴)(0.0530) = 3.604×10⁻⁵
x = √(3.604×10⁻⁵) = 0.0060 M

x / C = 0.0060 / 0.0530 = 0.113 or 11.3%

Conclusion: More than 5%, so cannot use approximation.

Step 2: Use full equation

x² / (0.0530 - x) = 6.8×10⁻⁴
→ x² = 6.8×10⁻⁴(0.0530 - x)
→ x² + 6.8×10⁻⁴x - 3.604×10⁻⁵ = 0

Solve quadratic:
a = 1, b = 6.8×10⁻⁴, c = -3.604×10⁻⁵
→ x = 0.00587 M

Step 3: pH = -log(0.00587) = 2.23


---

Case 3: [HF] = 0.0240 M

Step 1: Try x is small

x² = Ka × C = (6.8×10⁻⁴)(0.0240) = 1.632×10⁻⁵
x = √(1.632×10⁻⁵) = 0.00404 M

x / C = 0.00404 / 0.0240 = 0.168 or 16.8%

Conclusion: Still more than 5%, so cannot use approximation.

Step 2: Use full equation

x² / (0.0240 - x) = 6.8×10⁻⁴
→ x² + 6.8×10⁻⁴x - 1.632×10⁻⁵ = 0

Solve quadratic:
a = 1, b = 6.8×10⁻⁴, c = -1.632×10⁻⁵
→ x = 0.00392 M

Step 3: pH = -log(0.00392) = 2.41

Quick Tip (Friendly tone)

To check if “x is small” can be used, remember the 5% rule:
If x / initial concentration < 0.05 (5%), you're safe! Otherwise, go with the quadratic.
